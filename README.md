# Serverless Function Execution

A lightweight, containerized platform for executing serverless functions written in Python and JavaScript. This project facilitates the execution of user-defined functions through a centralized dispatcher, leveraging Docker for environment isolation and scalability.

## Features

- 🚀 Multi-language Support (Python & JavaScript)
- 📦 Containerized Workers for isolated execution
- 🧠 Central Dispatcher for managing requests
- 🖥️ React-based Frontend for user interaction

### Installation

1. **Clone the Repository** <br>
git clone https://github.com/guptajatin/serverless-function-execution.git <br>
cd serverless-function-execution

2. **Start the Application** <br>
docker-compose up --build

3. **Access the Frontend** <br>
Open your browser and navigate to: http://localhost:3000
